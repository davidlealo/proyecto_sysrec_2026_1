### Uso de IA en la entrega midterm

- Usamos el autocompletado de VS Code como soporte para el desarrollo del código.
- Usamos Gemini para comentar el primer código usado, aunque no es el que utilizamos para los resultados finales, en este caso compartimos dicho link en el notebook correspondiente /enfoque_previo_midterm.
- Para crear la plantilla de overleaf se usó prism de OpenAI, que es una herramienta que usa un modelo de lenguaje, pero no entrega un link para compartir. En este caso le mostramos el proyecto inicial y el prompt fue el siguiente:

> Toma la estructura de este informe un crea una plantilla sin el contenido, porque eso lo escribiré luego
